# html_engine.pyを実装するうえで大事なポイント

====
目的
==

html_engine.pyはHTMLを生成するモジュールではない。

役割は

HTML
↓

KnowledgeResult

へ変換する「解析エンジン」である。

HTMLの構造・属性・イベント・コンポーネント情報を抽出し、
他のEngineやBlockBuilderへ渡すことを目的とする。

HTMLGenerator(html_generate.py)とは責務を完全に分離する。

---

html_generate.py

JSON
↓

HTML

---

html_engine.py

HTML
↓

KnowledgeResult

====
責務
==

HTMLEngineはBaseEngineを継承する。

責務は

・HTMLの正規化
・DOM解析
・タグ解析
・属性解析
・イベント解析
・構造解析
・KnowledgeResult生成

のみとする。

HTMLを書き換えたり生成したりしない。

====
Parserとの責務分離


HTMLEngineの中でBeautifulSoupを直接多用しない。

できる限り

HTMLParser

へ処理を委譲する。

例

HTMLEngine

↓

HTMLParser

↓

BeautifulSoup

将来Tree-sitterへ交換できるようにする。

====
Analyzerとの責務分離
==

HTMLEngineは各Analyzerを呼び出すだけにする。

DOMAnalyzer

AttributeAnalyzer

StructureAnalyzer

EventAnalyzer

ScriptAnalyzer（将来）

CSSAnalyzer（将来）

Engineに大量の解析コードを書かない。

====

ScriptEngineとの連携
====

script本文は加工しない。

ScriptEngineへ渡す。

====
CSSEngineとの連携
=

style本文は加工しない。

CSSEngineへ渡す。

====
BlockBuilderとの連携
====

component_tree

tags

attributes

をBlockBuilderが利用する。

EngineではUI生成を行わない。

====
PropertyPanelとの関係
=====

HTMLEngineはReactを知らない。

JSXを生成しない。

PropertyPanelを知らない。

JSONだけ返す。

====
設計思想
====

HTMLEngineは解析専門。

Generatorは生成専門。

Parserは解析のみ。

Analyzerは知識抽出のみ。

HandlerはEngineの管理のみ。

BlockBuilderはUIモデル生成のみ。

責務を混在させないこと。
