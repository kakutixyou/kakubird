## テーマ分析機能

`/analysis` 画面で、Qiita・GitHub・YouTubeを選び、テーマと分類を指定して横断検索できます。`apple`/`りんご`や`株`/`stock`などの一般的な表記ゆれを追加して検索します。記事・リポジトリ・動画は各サービスの公開APIから取得します。

バックエンド起動前に依存関係をインストールしてください。

```bash
pip install requests
```

YouTube Data API v3をGoogle Cloudで有効化してAPIキーを取得し、バックエンド環境変数 `YOUTUBE_API_KEY` に設定してください。キーが未設定でもQiita/GitHubは利用でき、YouTubeは警告として表示されます。

- API: `POST /api/topic-analysis`
- `category`: `すべて`、`料理`、`料金`、`美味しさ`、`検索`、`株価`、`売買理由`
- YouTube結果には動画の10・20・30秒位置へ移動するリンクを表示します（動画内容の文字起こしや区間要約ではありません）。
- 株の勝ち/負け/理由は公開検索結果のタイトル・概要にある語の出現数です。実際の損益額や取引件数を推定したり、投資助言を行う機能ではありません。
