# Shooter Templates

このフォルダは、シューティングゲーム向けのゲーム生成モデルを格納するためのテンプレート群です。

- shooter_game_template.json: 全体設定
- item_library.json: アイテム定義
- boss_profile.json: ボス設定
- player_profile.json: プレイヤー設定
- asset_manifest.json: 背景・敵・味方・アイテムのアセット定義

初期設定:
- 3秒ごとにアイテムドロップ
- 永続: 攻撃力 +3
- 10秒間: 全ダメージ無効化
- ボスHP: 200
- 残機: 2
